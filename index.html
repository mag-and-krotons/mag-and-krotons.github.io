Platform Recommendation: WordPress.org vs. Modern Static Architecture

You asked if WordPress.org is good for hosting research papers, LaTeX math, and connecting GitHub. Here is our direct evaluation:

Architectural Verdict

WordPress.org (Suboptimal for Academic Research)

  • ❌ Requires Server & DB Hosting: Needs monthly paid hosting (Bluehost, DigitalOcean) with PHP & MySQL management.
  • ❌ Fragile LaTeX & Math Formatting: KaTeX / MathJax plugins frequently break on core updates and slow down page rendering.
  • ❌ Poor GitHub Ergonomics: Syncing code repos, stars, or version tags requires heavy, clunky plugins.
  • ❌ Security Overhead: WordPress sites are prime targets for automated bots; require constant patch updates.
  • ❌ Limited Aesthetic Freedom: Bloated corporate templates, hard to build bespoke 80s neon/synthwave visuals.

Static Jamstack + GitHub Pages / Cloudflare Pages (Recommended!)

  • ✅ 100% Free Forever: Zero hosting costs on GitHub Pages or Cloudflare Pages CDN with free SSL/HTTPS.
  • ✅ Native GitHub Ecosystem: Directly link or embed repos, releases, and automatically build/deploy with git push.
  • ✅ Blazing LaTeX / KaTeX Performance: Instant sub-millisecond math rendering directly in browser client.
  • ✅ Paper & License Management: Host PDFs directly in the git repository with exact versioning and Open Access licenses.
  • ✅ Unconstrained Visual Aesthetics: Full control over 80s neon synthwave styling, animations, and custom interactive labs.
